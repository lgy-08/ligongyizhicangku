# 手动验收清单（真实 Chrome）

单元测试不能代替本清单。每一项请填写**实际观察到的结果**，不通过时附截图或诊断 JSON。

## 准备

1. `npm install`，然后 `npm run dict -- --download`（只需一次；没有网络时可改用已有的 `data-src/ecdict.csv`）。
2. `npm run build`。
3. `chrome://extensions` → 打开“开发者模式” → “加载已解压的扩展程序” → 选择 `.output\chrome-mv3`。
4. 准备一个英文 YouTube 视频，以及与之对应的 SRT 或 VTT 文件。没有现成文件时，可用 `fixtures\sample-en.srt` 检查同步和跳转（它的时间点是通用的，内容与视频无关）。
5. 测试 A3–A5（导入文件）时，导入的字幕会优先显示，YouTube 原字幕框恢复显示；如果两层重叠，请关闭 CC。测试 C 节（YouTube 字幕模式）时需要打开 CC。

## A. LL-002 验收标准

| 编号 | 对应验收标准 | 步骤 | 预期 | 实际 |
|---|---|---|---|---|
| A1 | 1 自行加载 | 按“准备”加载扩展 | 无报错；扩展卡片不要求任何权限；点击工具栏图标打开“生词本与设置”页 | |
| A2 | 2 不打扰 | 打开任意观看页，正常看 3 分钟，不操作扩展 | 只在左上角出现半透明的“LL”小按钮；无弹窗、无暂停、无声音变化 | |
| A3 | 3 同步 | 点“LL”→“导入字幕文件…”，选择字幕文件，播放 | 提示导入条数；字幕在视频下方随播放切换，与对白时间一致 | |
| A4 | 3 拖动后跟上 | 暂停时拖动进度条；播放时拖动进度条；用键盘左右方向键快进快退 | 每种情况下字幕立即切换到新位置对应的句子 | |
| A5 | 3 字幕列表 | “LL”→“字幕列表”，点击任意一行 | 视频跳到该句开始处，当前句在列表中高亮 | |

| A7 | 4 无释义 | 点击专有名词或生造词 | 词卡明确显示“暂无释义”；“添加我的释义”可保存，再次点击能看到 | |

| A9 | 6 在生词本修改 | 打开设置页“生词本”，修改某个词的状态，再删除另一个词 | 修改立即生效；回到 YouTube 刷新并重新导入字幕后，高亮与生词本一致 | |
| A10 | 5 刷新保留 | 标记若干词后刷新 YouTube 页面，重新导入字幕 | 标记全部保留 | |

| A12 | 7 无字幕 | 打开一个**没有任何字幕**的视频，不导入文件，点“LL” | 菜单提示打开 CC 或“正在等待 YouTube 字幕…可以导入 SRT/VTT 文件”；页面其他功能正常 | |
| A13 | 7 无网络 | 断开网络后刷新已缓存的 YouTube 页面或打开本地 SRT 测试，查词并标记 | 查词、标记、生词本、导出全部可用（本地功能不依赖网络） | |
| A14 | 9 导出 | 设置页点“导出 JSON 备份” | 下载 `lingualens-backup-日期.json`；文件含 `"format": "lingualens-backup"` 和 `"schemaVersion": 1` | |
| A15 | 9 导入 | 在生词本删除几个词，再导入刚才的文件 | 提示新增条数；被删除的词恢复；重复导入提示“保持不变” | |
| A16 | 9 导入错误文件 | 导入一个任意的非备份 JSON 或文本文件 | 显示清晰的错误信息，数据不变 | |
| A17 | 8 无上传 | 打开 DevTools → Network，筛选扩展发起的请求，完成 A3–A8 | 除扩展自身的 `chrome-extension://…/dict/ecdict-lite.json` 外没有任何请求 | |
| A18 | 2 快捷键 | 词卡打开时按空格、K、F；在“我的释义”输入框中输入含 k、f、空格的文字 | 前者正常控制 YouTube；在输入框中打字不会触发暂停或全屏 | |
| A19 | 全屏 | 进入全屏和剧场模式，重复 A3、A6 | 字幕和词卡在全屏下可见，不遮挡底部原生控件 | |

## C. YouTube 字幕模式（尽力而为）

前提：没有导入字幕文件；设置中“使用 YouTube 字幕”为开启（默认）。分别用**人工字幕**和**仅自动生成字幕**的视频各测一遍。

| 编号 | 步骤 | 预期 | 实际（人工字幕） | 实际（自动字幕） |
|---|---|---|---|---|
| Y1 | CC 关闭时点“LL” | 菜单提示“请点击播放器右下角的 CC 按钮…” | | |
| Y2 | 打开 CC，播放 | 视频下方出现我们的字幕框，左上角小字“YouTube 字幕 · 尽力而为”；YouTube 原字幕框不可见，不出现两层重复文字 | | |
| Y3 | 播放 1 分钟 | 字幕文字随 YouTube 字幕变化；记录是否有明显延迟、闪烁或残留 | | |
| Y4 | 点击字幕中的单词 | 打开词卡；可标记状态；同一词元在后续字幕中按状态高亮 | | |
| Y5 | 自动字幕滚动时点击单词 | 词卡保持打开，不因字幕滚动而关闭；记录逐词滚动是否影响点击 | | |
| Y6 | “LL”→ 取消勾选“使用 YouTube 字幕” | 我们的字幕框消失，YouTube 原字幕框立即恢复显示 | | |
| Y7 | 重新勾选后导入一个 SRT 文件，再“清除字幕” | 导入后显示文件字幕，YouTube 原字幕框恢复；清除后回到 YouTube 字幕模式 | | |
| Y8 | 切换到另一个视频 | 旧视频的字幕不残留；新视频打开 CC 后正常显示 | | |
| Y9 | 在 YouTube 字幕设置中切换语言或改字号 | 我们的字幕跟随显示所选语言的文字（字号样式不跟随，属已知限制） | | |
| Y10 | 拖动 YouTube 原字幕框的位置（关闭本模式时拖动，再开启） | 记录我们的字幕位置（固定在底部，不跟随拖动，属已知限制） | | |

## D. 已出现的字幕列表（YouTube 字幕模式）

前提：YouTube 字幕模式开启，CC 打开，没有导入字幕文件。

| 编号 | 步骤 | 预期 | 实际 |
|---|---|---|---|
| T-1 | 连续播放 1 分钟，LL →“已出现的字幕” | 右侧列表按顺序列出出现过的句子，没有时间、不能跳转；当前句绿色高亮并自动滚动 | |
| T-2 | 拖到较后的位置播放 20 秒，再看列表 | 新句子排在后面；两段之间有“…… 中间有一段没有播放过 ……” | |
| T-3 | 拖回开头附近播放 20 秒 | 已有句子不重复；补看的句子插到前面正确位置 | |
| T-4 | 把 T-2 中跳过的那一段完整补看 | 该段的“没有播放过”提示消失 | |
| T-5 | 点击列表中的单词 | 打开词卡（列表上半部分的词，词卡出现在词的下方）；标记后列表与字幕中的高亮同步 | |
| T-6 | 自动生成字幕的视频播放 1 分钟 | 逐词出现的同一行被合并；记录半句话或重复的大致比例 | |
| T-7 | 有广告的视频，在广告期间打开 CC | 广告字幕不进入列表 | |
| T-8 | 切换到另一个视频 | 列表清空，不出现上一个视频的句子（包括切换瞬间仍显示的上一句） | |
| T-9 | 刷新页面 | 列表清空（只在当前页面有效） | |
| T-11 | 播放到较后位置（例如 3 分钟以后），然后把进度条一直拖回视频开头，再播放 30 秒 | 列表最下面不出现与前面相同的句子；开头部分不重复；顺序与视频一致 | |
| T-10 | 在同一视频中来回拖动进度条 5 次以上（向后、再拖回、再向后），每次播放 10 秒以上 | 没有重复的句子；顺序与视频一致。若仍有问题，开启诊断面板后复现，点 “Copy diagnostics JSON”，把内容和视频链接发给开发者 | |

## E. 短语查询与半透明词卡

| 编号 | 步骤 | 预期 | 实际 |
|---|---|---|---|
| P-1 | 在含常见短语的字幕中点短语里的一个词（如 looking forward to 中的 looking） | 词卡顶部出现黄色“所在短语”，显示 look forward to 及释义 | |
| P-2 | 按住鼠标从短语首词拖到末词松开 | 拖动过程中选中的词高亮；松开后弹出短语词卡，显示词典释义 | |
| P-3 | 点一个词，再 Shift+点击同一行另一个词 | 弹出这一段的短语词卡 | |
| P-4 | 拖选一段不是短语的词（如 “fact I”） | 提示“短语词典中没有”，若其中含短语则列出 | |
| P-5 | 拖动选择时把鼠标移到视频画面上再松开 | 正常弹出词卡；视频不会被暂停或切换全屏 | |
| P-6 | 在自动生成字幕（逐词滚动）中拖选 | 能正常选中；若字幕在拖动中变化，按开始拖动时的文字查询 | |
| P-7 | 字幕两行时点下面一行的词；再点上面一行的词 | 词卡都在整个字幕框上方，不遮挡任何英文行；内容多时词卡内部滚动 | |
| P-8 | 设置页调“词卡不透明度”为 40%、78%、100%，每次刷新页面后查词 | 透明度随设置变化；40% 时在明亮画面上文字仍可读 | |
| P-9 | 在“已出现的字幕”列表中点词、拖选 | 同样可以查词和查短语；词卡在列表上半部分时显示在词的下方 | |
| P-10 | 拖选后按空格键 | YouTube 正常暂停/播放，没有被我们的界面拦截 | |

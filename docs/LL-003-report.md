# LL-003 网页查词：阶段报告

- 日期：2026-10-09
- 依据：用户批准“按 B 做”，即作为 LinguaLens 的新模块（与 YouTube 共用词典和生词本），而不是独立扩展。
- 用户确定的范围：点击启用；只做单词和短语的词典查询；不接入机器翻译。

## 1. 做了什么

| 部分 | 内容 |
|---|---|
| 工具栏弹窗 | 点击扩展图标弹出小窗口：普通网页显示“在本页启用查词 / 在本页停用查词”；YouTube 页面提示由扩展自动支持；浏览器设置页、扩展商店、无法注入的页面提示不支持；底部可打开生词本与设置 |
| 按需注入 | `web-lookup.js` 不在 manifest 中，只在用户点击后通过 `scripting.executeScript` 注入当前标签页（`activeTab` 授权）；启用后图标显示蓝色 ON 角标，页面开始加载新文档时 background 清除角标 |
| 查词交互 | 被动监听 mouseup（不拦截网页事件）：选中 1 个英文单词（双击即可）→ 单词词卡，并根据所在文本查找“所在短语”；选中 2–12 个词 → 短语词卡；超过 12 个词、超过 200 字符、含中日韩文字 → 视为复制，不弹出 |
| 排除区域 | 输入框、文本框、下拉框、可编辑区域、`code` / `pre` / `kbd` / `samp` |
| 关闭词卡 | 点页面其他地方、按 Esc、滚动页面 |
| 界面隔离 | 词卡挂在 `<html>` 上的 shadow root 图层中，不受网页样式影响；词卡内的点击和按键不会传给网页；图层本身不拦截网页点击 |
| 词卡位置 | 选中文字下方，空间不足时放在上方；高度按可用空间限制，不遮挡选中的文字；透明度沿用“词卡不透明度”设置 |
| 共用生词本 | 在网页词卡中标记的状态写入同一个 IndexedDB，与 YouTube 共用 |
| 重构 | 词卡逻辑抽成 `CardController`，词卡界面抽成 `WordCard.tsx`，样式抽成 `card.css`，YouTube 叠加层与网页查词共用；YouTube 行为不变（重构后原有 204 个测试全部通过） |
| 权限 | 由 `[]` 变为 `['activeTab', 'scripting']`；仍然没有 `host_permissions`，不申请“所有网站”权限 |

## 3. 没验证什么

**真实 Chrome 中的全部行为尚未验证**，见 `docs/manual-test.md` F 节 W-1 至 W-16。重点风险：

1. 不同网站的结构差异：部分网站自定义了双击或选择行为，可能与查词冲突。
2. 单页应用：内容切换不会重新加载页面，查词保持启用，但 ON 角标是否被错误清除未知。
3. 嵌入的子页面（iframe）中不生效：注入只针对顶层页面。
4. 本地文件需要用户在扩展详情中开启“允许访问文件网址”。

## 4. 已知限制

- 每次刷新或跳转页面后需要重新启用。
- 选中 2–12 个词用于复制时，也会弹出短语词卡（点别处即关闭）。
- 被其他词隔开的短语、跨标点的短语查不到（与 YouTube 相同）。
- 短语不能加入生词本。
- 没有机器翻译。

## 6. 调整：网页单击查词、生词本中文释义（2026-10-09）

**单击查词**：
- 单击英文单词（鼠标未拖动、没有选中文字）时，根据点击位置找到单词，并确认点击确实落在这个单词的文字上（点在行尾空白处不算），然后弹出词卡。
- 不触发的情况：链接、按钮、表单控件等可交互元素；按住 Ctrl / Shift / Alt / Meta；非左键；排除区域（输入框、代码等）。
- 双击和拖选仍然有效；双击时第二次松开与第一次单击查的是同一个词，不会重复打开。
- 设置页新增“网页单击查词”开关（默认开启）；关闭后只响应双击和拖选。

**生词本中文释义**：
- 新增消息 `ll/define`：按词元批量返回词典中的音标和释义（每次最多 20,000 个）。
- 设置页生词本新增“释义”列，显示词典释义前两条；词典没有的词显示“暂无释义”；搜索框同时匹配英文和中文释义。
- 释义来自打包的词典，不写入生词本数据，因此备份文件格式不变。

**验证**（2026-10-09 本机实际运行）：类型检查通过；全部 240 个测试连续运行 10 次通过（新增：单词边界、可交互元素判断、单击查词流程（含链接、修饰键、多次点击、空白处、开关关闭）、批量释义接口、设置项）；构建成功，权限仍为 `activeTab, scripting`。happy-dom 没有页面排版，单击定位在测试中用可注入的假实现替代，**真实网页上的点击定位（`caretRangeFromPoint` 与“点在文字上”的判断）未验证**，见 `docs/manual-test.md` W-17 至 W-23。

**用户实测（2026-10-09）**：单击查词与生词本中文释义“验证通过”（未逐项填写 W-17 至 W-23）。

**已知限制**：在用脚本处理点击的网页元素上（没有使用标准链接或按钮标签），单击仍可能同时触发网页自己的动作和查词。
